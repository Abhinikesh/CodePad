# CodePad — Code & Notes Saver

> A sleek, dark-themed paste and code snippet manager. Save, organize, and access your code notes from anywhere.

🔗 **Live Demo:** [code-pad-eight.vercel.app](https://code-pad-eight.vercel.app)

## Features

- **Create Pastes** — Save code snippets or notes with a title
- **Persistent Storage** — All pastes synced to Supabase, survive tab/browser restarts
- **Device-scoped** — Each device has its own pastes via unique device ID
- **Search** — Instantly filter through saved pastes
- **Edit & Delete** — Full CRUD operations
- **Copy & Download** — One-click copy or download any paste
- **Dark UI** — Clean, minimal dark theme built with Tailwind CSS
